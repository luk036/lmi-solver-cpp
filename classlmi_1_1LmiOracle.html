Detailed Description

template<typename Vec, typename Mat = Eigen::MatrixXd>
requires detail::VecConcept<Vec> && detail::MatConcept<Mat>
class lmi::LmiOracle< Vec, Mat >

Oracle for standard LMI feasibility problems.

Evaluates the feasibility of a point x with respect to the LMI F0 - sum(x_k * F_k) ≻ 0 and returns a cutting-plane (subgradient, ep) when the LMI is violated.

Note
Concrete LMI oracle in the Template Method pattern: supplies a lazy getA accessor (F0 - Σ F_k x_k) with a positive sym_quad sign to the shared LmiOracleBase::assess_impl skeleton.

auto lmi::LmiOracle< Vec, Mat >::assess_feas ( const Vec &  x) -> Cut*

Assess feasibility of point x.

Constructs A = F0 - sum(x_k * F_k) and checks if it is SPD. If not, computes a witness direction (cut) for the cutting-plane method.

\[ A(x) = F_0 - \sum_{k=1}^{n} x_k F_k \succ 0 \]
