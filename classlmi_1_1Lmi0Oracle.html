Detailed Description

template<typename Vec, typename Mat = Eigen::MatrixXd>
requires detail::VecConcept<Vec> && detail::MatConcept<Mat>
class lmi::Lmi0Oracle< Vec, Mat >

Oracle for homogeneous LMI feasibility problems.

Evaluates feasibility of x with respect to the homogeneous LMI sum(x_k * F_k) ≻ 0 and returns a cutting-plane when the LMI is violated.

Note
Concrete LMI oracle in the Template Method pattern: supplies a lazy getA accessor (Σ F_k x_k) with a negative sym_quad sign to the shared LmiOracleBase::assess_impl skeleton.

Assess feasibility of point x for the homogeneous LMI.

Constructs A = sum(x_k * F_k) and checks if it is SPD. If not, computes a witness direction (cut) for the cutting-plane method.

\[ A(x) = \sum_{k=1}^{n} x_k F_k \succ 0 \]
